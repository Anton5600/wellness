Паттерн говорит «попробуй в 17:30», но:
Нет кнопки, чтобы запустить практику сейчас
Нет напоминания на 17:30
Нет доступа к практикам вне ритуала
Пользователь читает совет и... ничего не может сделать
Это разорванная петля: приложение даёт рекомендацию, но не даёт инструмент.
Минимальное исправление (эта итерация)
Добавить на карточку паттерна две кнопки действия:

┌────────────────────────────────────┐
│  📊 Наблюдение                     │
│                                    │
│  «Я замечаю, что к вечеру          │
│   тревога нарастает, а утром       │
│   ты обычно спокойнее.»            │
│                                    │
│  Попробуй «Вибро-ритм»             │
│  около 17:30.                      │
│                                    │
│  [▶ Попробовать сейчас]            │
│  [🔔 Напомнить в 17:30]           │
│                                    │
│  [Учесть в рекомендациях]          │
│  [Не показывать]                   │
└────────────────────────────────────┘

Кнопка 1: «Попробовать сейчас»
Открывает PracticePlayer с конфигурацией vibroPacing напрямую, минуя ритуал.
Практика запускается без инсайта, без выбора масла, без LLM-текста. Просто плеер.

Кнопка 2: «Напомнить в 17:30»
Ставит локальное уведомление через Capacitor:

По тапу на уведомление → открывается PracticePlayer с нужной практикой.
Расширенное исправление (следующая итерация)
«Практики по запросу» — раздел в Профиле
Пользователь должен иметь доступ к любой открытой практике в любой момент, не только через ритуал.

Профиль → Мои практики → [список открытых практик]

Каждая карточка:
┌────────────────────────────┐
│  🫁 Дыхание 4-4-6         │
│  Использована: 12 раз      │
│  Помогла: 80%              │
│  [▶ Начать]               │
└────────────────────────────┘

Паттерн без действия — это просто текст. Каждая рекомендация должна заканчиваться кнопкой, которую можно нажать прямо сейчас:
«Попробовать сейчас» → запускает практику
«Напомнить в 17:30» → ставит уведомление
«Учесть» → модифицирует движок
