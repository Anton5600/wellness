Смешанные эмоции (соседи по колесу)
Когда две соседние эмоции активны одновременно, возникают сложные чувства — самые распространённые в жизни:

| Пара эмоций         | Смешанная эмоция        | Когда возникает                                    |
| ------------------- | ----------------------- | -------------------------------------------------- |
| Радость + Доверие   | **Любовь**              | Привязанность, близость                            |
| Доверие + Страх     | **Покорность**          | Подчинение авторитету, страх перед начальником     |
| Страх + Удивление   | **Испуг**               | Внезапная угроза, рефлекс «замри»                  |
| Удивление + Печаль  | **Недоверие**           | Разочарование, предательство ожиданий              |
| Печаль + Отвращение | **Горечь**              | Тяжёлая утрата, ощущение несправедливости          |
| Отвращение + Гнев   | **Презрение**           | Моральное превосходство, отвержение другого        |
| Гнев + Ожидание     | **Агрессивная надежда** | Оптимизм через борьбу, «мы всё сломаем и построим» |
| Ожидание + Радость  | **Оптимизм**            | Вера в хорошее будущее                             |
