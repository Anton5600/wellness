# Интеграция автообновлений Capgo (Capacitor Updater)

Мы успешно добавили поддержку **Capgo (`@capgo/capacitor-updater`)** в ваше приложение. Это передовая система беспроводных обновлений (Over-The-Air, OTA), которая позволяет вам мгновенно обновлять веб-код приложения (React, стили Tailwind, картинки, новые функции) в обход проверки в RuStore, Google Play или App Store.

---

## Почему Capgo — идеальный выбор для RuStore?

1. **Независимость от магазина:** Поскольку нативный плагин RuStore AppUpdate сложно настроить из-за отсутствия официальных пакетов в публичном реестре npm, Capgo является великолепной альтернативой.
2. **Мгновенная доставка:** Вы можете исправить баг или выпустить новую фичу, и ваши пользователи увидят изменения при следующем перезапуске приложения без скачивания нового APK-файла.
3. **Кроссплатформенность:** Работает одинаково на Android и iOS.
4. **Автоматический откат:** Если новая версия веб-кода аварийно завершится при старте, плагин Capgo автоматически вернет пользователя на предыдущую стабильную версию (для этого мы настроили вызов `initializeCapgoUpdate()` на старте, который подтверждает успешную загрузку).

---

## Что уже настроено в коде

1. **Конфигурация:** В `capacitor.config.ts` добавлен блок плагина с отключенным автоматическим фоновым обновлением (`autoUpdate: false`), чтобы вы могли полностью контролировать процесс в JavaScript-коде.
2. **Инициализация:** В `App.tsx` на старте вызывается функция `initializeCapgoUpdate()`, которая сообщает плагину, что приложение успешно загрузилось (`notifyAppReady()`).
3. **Модуль сервиса:** Создан файл `/services/capgoUpdate.ts`, содержащий функции инициализации и ручного обновления из произвольного `.zip` файла (Self-Hosting).

---

## Вариант 1: Использование облака Capgo (Рекомендуется)

Официальный облачный сервис Capgo берет на себя хостинг версий, аналитику и постепенное развертывание.

### 1. Подготовка и вход
1. Зарегистрируйтесь на сайте [capgo.app](https://capgo.app/).
2. Получите API-ключ в личном кабинете.
3. Установите CLI-утилиту глобально на вашем компьютере:
   ```bash
   npm install -g @capgo/cli
   ```
4. Войдите в аккаунт через консоль:
   ```bash
   capgo login <ВАШ_API_КЛЮЧ>
   ```

### 2. Первая инициализация приложения в облаке
Создайте проект в панели Capgo с вашим App ID (`com.wellness.app`):
```bash
capgo init
```

### 3. Сборка и отправка обновления
Каждый раз, когда вы хотите отправить пользователям новую версию:

1. Соберите веб-версию:
   ```bash
   npm run build
   ```
2. Отправьте билд в облако Capgo (укажите версию, например, `1.0.1`):
   ```bash
   capgo bundle upload -v 1.0.1
   ```
3. Сделайте эту версию активной по умолчанию для всех пользователей в панели управления Capgo.

## Вариант 2: Самостоятельный хостинг (Self-Hosting)

Если вы хотите полностью контролировать файлы обновлений и хранить их на своем собственном сервере без использования облака Capgo, вы можете сделать это абсолютно бесплатно.

### 1. Подготовка архива обновлений
1. Выполните сборку:
   ```bash
   npm run build
   ```
2. Перейдите в папку `dist` и запакуйте все ее содержимое в обычный `.zip` архив (все файлы, включая `index.html`, должны находиться в корне архива, без лишних вложенных папок).
3. Загрузите этот архив на ваш сервер, чтобы он был доступен по прямой ссылке, например:
   `https://my-server.com/updates/v1.0.1.zip`

### 2. Вызов обновления из React
Используйте готовую функцию `performManualUpdate` из файла `/services/capgoUpdate.ts`:

```typescript
import { performManualUpdate } from './services/capgoUpdate';

const handleUpdate = async () => {
  try {
    // Скачивание и активация обновления с вашего сервера
    await performManualUpdate('https://my-server.com/updates/v1.0.1.zip', '1.0.1');
    console.log('Обновление успешно установлено! Приложение перезапустится...');
  } catch (error) {
    console.error('Ошибка обновления:', error);
  }
};
```

При вызове этой функции плагин скачает архив, распакует его на устройстве, сделает активным и мгновенно перезагрузит Webview, чтобы пользователь сразу увидел обновленный интерфейс.
