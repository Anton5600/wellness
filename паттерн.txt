Баннер «Открылось: Паттерны»
Баннер в текущем виде — пустой шум.
Когда фича открывается, пользователь должен сразу получить от неё пользу, а не узнать, что она существует.
Сценарий 1: На 14-й день паттерны уже есть (данные накопились)
К 14-му дню у пользователя 14 записей. Этого достаточно для детекции минимум 1–2 паттернов. Вместо баннера «Открылось» показываем первый реальный паттерн прямо на главном экране:
┌────────────────────────────────────┐
│                                    │
│   🌿 Ритуал завершён              │
│   Масло: Лаванда ✓                 │
│                                    │
│   ─────────────────────────        │
│                                    │
│   📊 Первое наблюдение             │
│                                    │
│   ┌────────────────────────────┐   │
│   │  «Я замечаю, что к вечеру  │   │
│   │   в будни тревога          │   │
│   │   нарастает. Утром         │   │
│   │   ты обычно спокоен.       │   │
│   │                            │   │
│   │   Попробуй дыхание         │   │
│   │   в 17:30 — до того,       │   │
│   │   как волна поднимется.»   │   │
│   │                            │   │
│   │   [Подробнее]              │   │
│   │   [Учесть в рекомендациях] │   │
│   └────────────────────────────┘   │
│                                    │
└────────────────────────────────────┘

Что здесь важно:
Нет слова «Открылось». Пользователю неважно, что разблокировано. Ему важно, что он узнал.
Паттерн сформулирован как наблюдение, а не как системное сообщение.
Есть действие: «Учесть в рекомендациях» → движок корректирует вечернюю практику.
Есть «Подробнее» → переход на экран паттернов, если хочется увидеть остальные.

Сценарий 2: На 14-й день паттернов ещё нет (данных мало)
Бывает, если пользователь делал чек-ины не каждый день или данные слишком однородные. Тогда показываем объяснение, а не пустой баннер:

┌────────────────────────────────────┐
│                                    │
│   🌿 Ритуал завершён              │
│   Масло: Лаванда ✓                 │
│                                    │
│   ─────────────────────────        │
│                                    │
│   📊 Наблюдения                    │
│                                    │
│   ┌────────────────────────────┐   │
│   │  За 14 дней я начал        │   │
│   │  замечать закономерности,   │   │
│   │  но пока их мало для       │   │
│   │  уверенного вывода.        │   │
│   │                            │   │
│   │  Через 3-5 дней ритуала    │   │
│   │  появится первое           │   │
│   │  наблюдение.               │   │
│   └────────────────────────────┘   │
│                                    │
└────────────────────────────────────┘

Что здесь важно:
Честность: «пока мало данных».
Конкретный срок: «через 3-5 дней».
Нет пустого празднования.
Сценарий 3: Паттерн обнаружен не в день разблокировки, а позже
Если разблокировка была на 14-й день, но первый паттерн появился на 17-й — показываем его в тот момент, когда он появился, а не привязываем к дате разблокировки:

День 17, утренний экран:

┌────────────────────────────────────┐
│                                    │
│   Доброе утро. День 17.           │
│                                    │
│   📊 Новое наблюдение              │
│                                    │
│   ┌────────────────────────────┐   │
│   │  «Когда ты пишешь о        │   │
│   │   встречах, страх          │   │
│   │   растёт. Это не           │   │
│   │   диагноз. Это             │   │
│   │   наблюдение.»             │   │
│   │                            │   │
│   │   [Подробнее]              │   │
│   │   [Не показывать]          │   │
│   └────────────────────────────┘   │
│                                    │
│   [Как ты сейчас?]                 │
│                                    │
└────────────────────────────────────┘
