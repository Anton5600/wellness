# «Внутренний Компас» — защита проекта перед экспертами

> Мобильное приложение для эмоционального самопознания: гибридный ИИ-движок персональных рекомендаций на основе колеса эмоций Плутчика и ароматерапии dōTERRA.
> Стек: React 18 + Vite 5 + Capacitor 8 (клиент), Express 5 (сервер), Firebase Firestore/Auth (персистентность), Tailwind + Recharts (UI).

---

## 0. Резюме (elevator pitch)

Человек в стрессе не может сам назвать, что чувствует, и тем более — что с этим делать. Мы не «чат-бот для настроения», а **ежедневный ритуал**: короткий микро-ввод (слово, три кнопки или голос) → распознавание состояния через модель Плутчика → **одно конкретное действие** (масло + минутная дыхательная практика).

Принцип: **«Один день. Одна практика. Твоё спокойствие».** Одна рекомендация в день вместо бесконечной ленты советов — это сознательное ограничение когнитивной нагрузки и гарантия выполнимости шага.

## 1. Проблема и решение

| | Существующие дневники настроения | «Внутренний Компас» |
|---|---|---|
| Вход | Статичный выбор смайлика | Микро-ввод: слово / 3 кнопки / голос |
| Распознавание | Нет | Векторная модель Плутчика (8 координат) |
| Ответ | Ничем не подкреплённый текст | ОДНО действие: масло + дыхание |
| Обратная связь | Нет | Вечерний фидбек → движок переобучается |
| Приватность | Часто «серая» | По-владельцу в Firestore, PIN-лок |

## 2. Научно-методологическая база

Рекомендации строятся **не на магии LLM, а на детерминированной модели**:

- **Колесо Плутчика** (Robert Plutchik): 8 базовых эмоций — `joy, trust, fear, surprise, sadness, disgust, anger, anticipation`. Используем как **векторную модель состояния** — `PlutchikVector = Record<EmotionKey, number>` (8 координат 0..1). Это даёт воспроизводимость и объяснимость: каждый вывод прослеживается до правила.
- **Дыхательные паттерны** привязаны к состоянию: обычный `4-4-6`, при «застревании» — `4-4-4`.
- **Цвет дня** выводится из доминантной эмоции (палитра Плутчика); фон приложения мягко меняется под состояние, при смешанной эмоции — градиент.

## 3. Архитектура экранов (пространственный UX)

Глобальный паттерн: фон = «цвет дня». Переходы — плавные (fade/slide), без резких скачков.

### 3.1 Онбординг и калибровка
- **Сплэш**: слоган «Один день. Одна практика. Твоё спокойствие».
- **Шаг 1 — выбор времени** (утро/день/вечер) → настройка локальных пушей.
- **Шаг 2 — микро-квиз из 5 вопросов** (карточки вместо анкеты) → первичная настройка весов вектора Плутчика.
- **Шаг 3 — финал**: экран окрашивается в стартовый цвет, текст «Твоя стартовая точка задана» → «Начать первый ритуал».

### 3.2 Дашборд «Сегодня» (точка входа в привычку)
- Приветствие по хронотипу («Доброе утро» / «Время выдохнуть вечером»).
- **Мягкий индикатор стрика** — растущий росток/кристалл, не агрессивный огонь; при пропуске иконка «спит».
- **Карточка состояния** — крупная, тактильно приятная кнопка «Как ты сейчас?».
- Вечером — ненавязчивое напоминание «Как прошла практика с [маслом]?».
- Тапбар: **Сегодня (Ритуал) / Динамика (позже) / Профиль и Аптечка**.

### 3.3 Микро-ввод (шторка, 5–10 секунд)
Три переключателя:
- **Текст** (по умолчанию): «Одно слово или пара фраз».
- **Голос**: крупная кнопка микрофона (за рулём / нет сил печатать).
- **Кнопки для низкого ресурса**: 🟢 Норм / 🟡 Так себе / 🔴 Тяжело.
- Анимация анализа: «Слушаю тебя… Анализирую состояние…».

### 3.4 Инсайт и рекомендация («меня поняли»)
- Визуализация эмоции + текст «Похоже, сейчас преобладает тревога».
- **Инсайт от LLM**: 2–3 предложения, эмпатия без токсичного позитива.
- **Рецепт дня**: одно масло (+ кнопка «У меня этого нет» → альтернатива из аптечки или телесный якорь), паттерн дыхания, кнопка «Начать практику (1 минута)».

### 3.5 Практика (AromaBreathing Modal)
- Полноэкранно, экран смягчается; пульсирующий круг (вдох/задержка/выдох).
- Опционально: низкочастотный гул + мягкая вибрация.
- Таймер 60 секунд. Финал: «Отличная работа» → «Завершить ритуал».

### 3.6 История и динамика
- **Календарь эмоций** — месяц, раскрашенный цветами Плутчика.
- **График колеса** — упрощённый радар (восьмиугольник) доминант за неделю.
- **ИИ-инсайты**: «По вечерам у тебя растёт грусть — попробуем успокаивающие ароматы».

### 3.7 Профиль и аптечка dōTERRA
- **Аптечка** — список масел пользователя (галочки). Критично для движка: предлагать только то, что под рукой.
- **Каталог** — карточка dōTERRA + «Добавить в корзину».
- **Настройки** — уведомления, приватность (PIN-лок истории).

## 4. Путь пользователя по дням (временной UX, progressive disclosure)

Механика прогрессивного раскрытия: не вываливаем всё в первый день — растим пользователя вместе с привычкой.

| День | Событие | Механика под капотом |
|---|---|---|
| **1** | Aha-moment: первый чек-ин, распознали эмоцию, цвет, инсайт, дыхание | Динамика скрыта; связка «эмоция → действие → облегчение» |
| **2** | Возвращение; утренний пуш адаптирован под вчерашний результат | Второй вектор; контекст из вчерашнего дня |
| **3** | 🔓 Вечерний фидбек: «Помогла ли практика с [масло]?» | 👍/👎 → **правило бана**: «Хуже» исключает масло на 7 дней |
| **5** | 🔓 Карта дня: постер с цветом и доминантой за 5 дней | Начало коллекционирования состояний |
| **7** | Кризис недели: «Заморозка / бережный возврат» при пропуске | Укороченный ритуал без текста, только 3 кнопки |
| **10** | 🔓 Метафорические карты | Колода с терапевтическим вопросом дня |
| **14** | 🔓 Паттерны и динамика + первый еженедельный отчёт | Тренды, корреляция «стресс ↓ при хвойных ароматах» |
| **21** | 🔓 Каталог и глубокая работа с маслами | Сложные бленды по тонкой настройке вектора |
| **30** | 🔓 PDF-экспорт «Дневник месяца» | Переход в статус амбассадора привычки |

## 5. Критические микро-сценарии (краевые случаи)

### 5.1 «У меня нет масла»
Движок рекомендует масло, которого нет в аптечке → кнопка «Нет под рукой» → ИИ пересобирает на лету: «Ладан можно заменить на [масло из аптечки], либо сенсорный якорь — потри ладони, поднеси к лицу, дыши 4-4-6».

### 5.2 «Красная зона» (кризис, self-harm)
Детерминированный движок **перехватывает управление ДО генерации LLM-ответа**. Стандартный инсайт отключается. Экран экстренной помощи: «Мне жаль, что тебе так тяжело. Я лишь приложение, но тебе может помочь специалист» + кнопки «Горячая линия» и «Техника заземления 5-4-3-2-1».

### 5.3 Офлайн
Микро-ввод работает локально (правила без LLM). Вместо сгенерированного текста — заготовленный шаблон поддержки. Дыхание и выбор масла работают на 100%. Бейдж «Синхронизируемся, когда появится сеть».

## 7. Гибридный движок рекомендаций — сердце продукта

**Слой 1 — детерминированный шортлист** (офлайн, работает всегда): по состоянию и контексту строится упорядоченный список масел по правилам.

**Слой 2 — LLM-синтез** (`DeepSeek → Gemini → локальный шаблон`): LLM получает уже отобранный шортлист и лишь формулирует `insight` / `tomorrowTeaser`. **LLM не выбирает масло из полного каталога** — это сужает пространство ошибок и защищает от галлюцинаций.

Три ключевых правила:
1. **Бан по эффективности** — фидбек «хуже» исключает масло на 7 дней.
2. **Форма колеса** — классификация распределения вектора (звезда/полумесяц/круг) меняет стратегию.
3. **Хронотип** — время суток влияет на уместность масел.

Контракт ответа: `{ plutchikInferred, insight, aroma, breathing, color, tomorrowTeaser }`.

## 8. Данные и мульти-девайсная синхронизация

**Единый контур рекомендаций** (`emotionalGraph`): локальный кеш в `localStorage` для мгновенной офлайн-работы + **Firestore как персистентная правда**.

- Запись: `setDoc(emotionalGraph/{uid}_{date})`, `plutchikProfiles/{uid}`, `streaks/{uid}`.
- Чтение на новом устройстве: локальный кеш пуст → подтягиваем из Firestore по `where('userId','==',uid)` → объединяем с локальным.
- **Результат**: пользователь с любого устройства получает свой кабинет — история, профиль, стрик, аптечка.

## 9. Безопасность и приватность

- **Правила Firestore** (`firestore.rules`): владелец читает/пишет только свои документы (`isOwner`), строгая валидация схемы (`isValidEmotionalGraphEntry`, `isValidPlutchikProfile`).
- Эмоциональные состояния — health-adjacent данные: хранение строго по `uid`, без публичного доступа, PIN-лок.
- Auth через Firebase, email-верификация.
- Политика конфиденциальности вынесена в отдельный документ.

## 12. Честные ограничения (называем сами, до вопросов)

- Эффективность рекомендаций пока не подтверждена клинически — это wellness, не медицина; позиционируем честно.
- Два исторических контура данных (`emotionHistory` и `emotionalGraph`) частично пересекаются — идёт миграция на единый.
- LLM-часть зависима от внешних провайдеров — потому и вынесена за детерминированный контур с локальным fallback.
