Главный принцип
Вход на следующий день — это не просто «новый ритуал». Это переход между вчерашним состоянием и сегодняшним. Если просто показать пустой экран «Как ты сейчас?», пользователь теряет контекст и ощущение непрерывности.
Но и грузить его вчерашней статистикой нельзя. Нужен мост длиной в 5 секунд: короткое признание вчерашнего дня → плавный переход к сегодняшнему ритуалу.

Логика движка:
Если пользователь прервал практику на 50%+ → предлагаем завершить
Если прервал на <20% → предлагаем начать заново
Если вчера был критический пульс → не напоминаем о незавершённом, просто предлагаем новый день

Важно: Никакого «Ты пропустил день!» или «Стрик потерян!». Формулировка: «Мы не считаем пропуски. Мы считаем возвращения».
Стрик: Не сбрасывается мгновенно. Даём «грейс-период» — 1 пропущенный день не ломает стрик. Сброс только после 2+ пропущенных дней.

Общая структура экрана входа
Независимо от сценария, экран входа имеет три зоны:
┌────────────────────────────────────┐
│  ЗОНА 1: Приветствие + Контекст    │
│  (время суток, стрик, вчерашний    │
│   итог — 2-3 строки)              │
│                                    │
│  ─────────────────────────────     │
│                                    │
│  ЗОНА 2: Мост (опционально)       │
│  (вчерашний фидбек, незавершённая  │
│   практика, разблокировка)         │
│  Показывается ТОЛЬКО если нужно    │
│                                    │
│  ─────────────────────────────     │
│                                    │
│  ЗОНА 3: Призыв к действию        │
│  [Как ты сейчас?]                 │
│  Главная кнопка. Всегда видна.     │
│                                    │
└────────────────────────────────────┘
Правило: Зона 3 (кнопка «Как ты сейчас?») всегда видна без скролла. Даже если Зона 2 большая.
Время суток влияет на приветствие
// core/greeting.ts

function getGreeting(
  timeOfDay: 'morning' | 'afternoon' | 'evening',
  dayNumber: number,
  streak: number,
  yesterdayCompleted: boolean
): Greeting {
  
  const greetings = {
    morning: {
      fresh: ['Доброе утро.', 'Новый день.', 'Утро.'],
      returning: ['С возвращением.', 'Доброе утро.'],
      afterMiss: ['С возвращением.', 'Рада, что ты здесь.'],
    },
    afternoon: {
      fresh: ['Добрый день.', 'Продолжаем.'],
      returning: ['С возвращением.'],
      afterMiss: ['Рада, что ты здесь.'],
    },
    evening: {
      fresh: ['Добрый вечер.', 'Время выдохнуть.'],
      returning: ['С возвращением.'],
      afterMiss: ['Рада, что ты здесь.'],
    },
  };
  
  const type = !yesterdayCompleted ? 'afterMiss' 
             : dayNumber === 1 ? 'fresh' 
             : 'returning';
  
  const options = greetings[timeOfDay][type];
  const text = options[Math.floor(Math.random() * options.length)];
  
  return { text, dayNumber, streak };
}
Цвет фона при входе
Фон экрана входа — не вчерашний цвет и не пустой. Это нейтральный градиент, который ждёт нового ввода:
Вход на новый день:
  Фон = мягкий серо-бежевый (нейтральный)
  
После ввода эмоции:
  Фон плавно перетекает в цвет новой эмоции
  
Если пользователь не вводит эмоцию (просто смотрит):
  Фон остаётся нейтральным
  Через 30 секунд — мягкая пульсация кнопки «Как ты сейчас?»
Исключение: Если вчера был критический пульс (паника, острый стресс), фон при входе сегодня — мягкий тёплый (не нейтральный). Это создаёт ощущение безопасности: «Вчера было тяжело, но сегодня — новый день, и здесь безопасно».
Данные, которые определяют сценарий входа
// services/entryService.ts

interface EntryContext {
  timeOfDay: 'morning' | 'afternoon' | 'evening';
  dayNumber: number;
  streak: number;
  
  yesterday: {
    completed: boolean;        // ритуал завершён?
    eveningFeedbackDone: boolean;  // фидбек сделан?
    practiceInterrupted: boolean;  // практика прервана?
    practiceProgress: number;      // 0..1 (если прервана)
    hadCriticalPulse: boolean;     // был критический пульс?
    color: string;                 // вчерашний цвет
    oil: string;                   // вчерашнее масло
  };
  
  today: {
    isUnlockDay: boolean;     // день разблокировки?
    unlockFeature: string | null;  // что разблокируется?
    isCalibrationDay: boolean;  // день калибровки?
  };
}

function determineEntryScenario(ctx: EntryContext): EntryScenario {
  // Приоритет 1: Пропущенный день
  if (!ctx.yesterday.completed && ctx.streak > 0) {
    return 'missed_day';
  }
  
  // Приоритет 2: Критический пульс вчера
  if (ctx.yesterday.hadCriticalPulse) {
    return 'gentle_return';
  }
  
  // Приоритет 3: Незавершённая практика
  if (ctx.yesterday.practiceInterrupted && ctx.yesterday.practiceProgress > 0.5) {
    return 'unfinished_practice';
  }
  
  // Приоритет 4: Вечерний фидбек не сделан
  if (ctx.yesterday.completed && !ctx.yesterday.eveningFeedbackDone) {
    return 'pending_feedback';
  }
  
  // Приоритет 5: Разблокировка
  if (ctx.today.isUnlockDay) {
    return 'unlock_day';
  }
  
  // Приоритет 6: Калибровка
  if (ctx.today.isCalibrationDay) {
    return 'calibration_day';
  }
  
  // По умолчанию: чистый новый день
  return 'fresh_day';
}
Микро-анимации при входе
Сценарий
Анимация
Идеальный возврат
Карточка «Вчера» плавно появляется, затем сжимается до строки
Незавершённая практика
Незавершённая практика показана как полупрозрачная карточка с пульсирующей кнопкой «Завершить»
Пропущенный день
Экран плавно «вдыхает» (масштаб 0.98 → 1.0), как будто приложение «просыпается»
Разблокировка
После ритуала — конфетти из частиц цвета новой фичи
Критический пульс вчера
Фон мягко пульсирует тёплым светом, как «объятие»
Итого: Что пользователь видит в первые 5 секунд
Секунда 1: Приветствие + фон
  «Доброе утро.» / «С возвращением.»

Секунда 2-3: Контекст (если нужен)
  Карточка «Вчера» / Фидбек / Незавершённая практика

Секунда 4-5: Призыв к действию
  [Как ты сейчас?]
  
  ← Пользователь тапает → Ритуал начинается
Никаких модальных окон. Никаких «Добро пожаловать обратно! Вот ваша статистика за вчера!». Всё компактно, всё на одном экране, всё ведёт к одной кнопке: «Как ты сейчас?».
